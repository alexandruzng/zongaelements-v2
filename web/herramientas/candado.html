¿Por qué no se puede abrir antes?
  • El código se cifra en tu dispositivo para una ronda futura de drand (red «quicknet»), una red pública de aleatoriedad mantenida por universidades y empresas que publica una firma cada 3 segundos.
  • La llave para descifrarlo es la firma de esa ronda, que no existe hasta la fecha elegida. No hay contraseña maestra ni nada guardado en ningún servidor: tampoco el dueño de la web puede abrirlo antes.
  • Cambiar la hora del móvil no sirve: lo que manda es la ronda publicada por drand.
  • Aquí solo se guarda el texto cifrado (en este navegador, en el enlace y en tu .txt). Si borras todo y no tienes copia, el código se pierde.
  • Si esta web desapareciera, tu .txt se puede abrir en la fecha con la herramienta oficial timevault.drand.love.
